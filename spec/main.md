# main functionality
1. channel search (e.g. search MKBHD channel for the latest iphone review)
2. list all video channels
    - filter by date (e.g. ... from the last year)
3. video transcripts extraction with timestamps
    - example: marquess mentions in [03:15] that the battery is 17% larger than previous year.
4. video description
    - for external links and citation by the creator.
